# 🌐 网页保存到飞书 Chrome插件

一个功能完整的Chrome浏览器插件，用于一键保存当前网页到飞书多维表格，支持自定义备注和标签。

## ✨ 功能特性

- 🚀 **一键保存** - 点击图标即可保存当前网页
- 📝 **自定义备注** - 为保存的网页添加个人备注
- 🏷️ **标签管理** - 支持自定义标签，便于分类整理
- 📊 **多表格支持** - 可配置多个飞书多维表格
- 🔍 **URL解析** - 智能解析飞书表格链接
- 🔐 **权限检查** - 一键检查表格访问权限
- 📋 **历史记录** - 查看最近的保存记录
- 🔄 **自动刷新** - 开发时支持一键刷新插件

## 🚀 安装方法

### 方法1：从Chrome网上应用店安装（推荐）
1. 打开Chrome浏览器
2. 访问Chrome网上应用店
3. 搜索"网页保存到飞书"
4. 点击"添加到Chrome"

### 方法2：手动安装（开发者版本）
1. 下载最新版本的插件文件
2. 打开Chrome浏览器
3. 访问 `chrome://extensions/`
4. 开启右上角的"开发者模式"
5. 点击"加载已解压的扩展程序"
6. 选择插件文件夹

## 🔧 配置说明

### 1. 配置飞书访问令牌
1. 访问[飞书开放平台](https://open.feishu.cn/)
2. 创建企业自建应用
3. 在权限管理中添加：
   - `bitable:app`（必需）
   - `bitable:app:readonly`（推荐）
   - `base:record:retrieve`（推荐）
4. 发布应用
5. 获取 `app_access_token`
6. 在插件中点击右上角⚙️按钮配置令牌

### 2. 添加飞书多维表格
1. 打开飞书多维表格
2. 点击"分享"获取分享链接
3. 在插件中选择"+ 添加新表格链接"
4. 粘贴分享链接并命名
5. 点击"🔍 测试解析"验证链接
6. 点击"🔐 检查权限"确认访问权限

### 3. 表格字段要求
确保你的飞书多维表格包含以下字段：
- **标题**（单行文本）
- **链接**（单行文本）
- **备注**（多行文本，可选）
- **标签**（单行文本，可选）
- **保存时间**（单行文本或日期）

## 📋 使用方法

### 基本使用流程
1. 浏览任意网页
2. 点击插件图标
3. 查看自动获取的页面标题
4. 添加个人备注（可选）
5. 输入相关标签（可选）
6. 选择目标飞书表格
7. 点击"💾 保存到飞书"

### 高级功能
- **URL测试**：使用"🔍 测试解析"验证链接格式
- **权限检查**：使用"🔐 检查权限"确认访问权限
- **历史记录**：查看最近5条保存记录
- **多表格管理**：添加和管理多个飞书表格

## 🔍 故障排除

### 常见问题

#### 1. 权限被拒绝 (Permission denied)
**解决方案**：
- 关闭飞书多维表格的"高级权限"
- 确保应用具有正确的权限配置
- 重新获取访问令牌

#### 2. URL解析失败
**解决方案**：
- 确保链接包含 `?table=` 参数
- 使用"🔍 测试解析"功能验证
- 检查链接格式是否正确

#### 3. 保存失败
**解决方案**：
- 检查表格字段是否配置正确
- 确认表格分享权限
- 查看详细错误信息
